# 🍱 점심밥 추천 서비스
짧은 점심 시간, 내 근처에 어떤 맛집들이 있는지 알려주는 서비스 입니다.

## 주요 기능
- 📍 위치 기반 맛집 추천
- 🔁 랜덤 추천 기능
- 💬 (제공 예정) 위치 기반 사용자 소통 기능

## 🛠️ 기술 스택
- Frontend: React, TypeScript
- Backend: Java, Spring, Python, FastAPI
- Database: MySQL
- 기타: KakaoMap API, Google Place API
